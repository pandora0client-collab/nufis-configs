# Nufis Cloud Configs 🚀

Oficjalna chmura konfiguracji dla **Nufis Client** oraz **Nufis Discord Bot**.

## 🌐 Strona Web (GitHub Pages)
Odwiedź stronę, aby przeglądać i pobierać konfiguracje:
👉 **[https://pandora0client-collab.github.io/nufis-configs/](https://pandora0client-collab.github.io/nufis-configs/)**

---

## 🎮 Jak załadować konfigurację w grze?
1. Skopiuj kod konfiguracji (np. `NF-ANARCHIA1`, `NF-LEGITPVP`, `NF-CRYSTAL1`, `NF-DEFAULT`).
2. Włącz **Minecraft** z Nufis Client 1.0.4.
3. Wciśnij **Prawy Shift** &rarr; przejdź do zakładki **Configs**.
4. Kliknij **Import**, wklej kod i kliknij **Import**!
5. Nowe moduły, binds, HUD i ustawienia AutoMarket zostaną załadowane natychmiast!

---

## 🤖 Jak używać z Nufis Discord Bot?
- `/config get <KOD>` — pobiera konfigurację i generuje plik `.Nuf`
- `/config share <nazwa> <plik_lub_kod>` — udostępnia konfigurację w chmurze i generuje kod `NF-...`
- `/config list` — wyświetla listę dostępnych konfiguracji

---

## 📦 Struktura Repo
- `configs/` — pliki JSON poszczególnych konfiguracji (`NF-*.json`)
- `index.json` — rejestr wszystkich konfiguracji dla klienta i bota
- `index.html` — interaktywna strona web
